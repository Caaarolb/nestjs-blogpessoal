# Blog Pessoal - NestJS

Este repositório contém um projeto de blog pessoal utilizando o framework **NestJS**, criado como parte de aulas da **Generation Brasil**.

## Descrição

Este projeto utiliza o NestJS, um framework Node.js para construir aplicações escaláveis e eficientes. O sistema é um blog pessoal simples, com funcionalidades básicas para gerenciar posts.

## Tecnologias Utilizadas

- **NestJS**: Framework para a criação da API.
- **TypeScript**: Linguagem principal do projeto.
- **PostgreSQL** (se configurado): Banco de dados utilizado para armazenar os posts.

## Como Rodar o Projeto

### 1. Clonando o Repositório

```bash
git clone https://github.com/Caaarolb/nestjs-blogpessoal.git
cd nestjs-blogpessoal

```

2. Instalando as Dependências
```
npm install
```

3. Rodando em Modo Desenvolvimento
```
npm run start:dev
```
4. Rodando os Testes
Para rodar os testes unitários, utilize:
```
npm run test
```
5. Rodando os Testes End-to-End (E2E)
```
npm run test:e2e
```
